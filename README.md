## 🔨 Construction Sequence

1. **Floor Preparation** - Mark footprint, install base planks (173mm high)
2. **Left Wall Extension** - Integrate with existing stud wall (extend 237mm)
3. **Metal Stud Frame** - Install tracks, studs (400mm centers), noggins
4. **Services** - Route tablet power, consider lighting
5. **Plasterboard** - Fix, cut access opening, tape/joint, finish
6. **Bed Frame** - Build 357mm surround with 18mm plywood
7. **Shelving** - Install rear (2246×210mm) and head (346×900mm) shelves
8. **Drawers** - Construct, install runners, fit and adjust
9. **Tablet Mount** - Install at center, 975mm height
10. **Finishing** - Curtains, mattress, safety checks

To adjust dimensions:

1. Edit measurements at top of `generate_cabin_bed_drawings.py`
2. Run: `python3 generate_cabin_bed_drawings.py`
3. New drawings will be generated with updated dimensions

Key variables:
```python

OVERALL_DEPTH = 1222
BED_WIDTH = 1900
BED_DEPTH = 900
PLATFORM_HEIGHT = 530
```
