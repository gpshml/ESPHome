### 3. DRAWERS (×2)

#### Drawer Dimensions Calculation
Total bed width: 1900mm  
Leg configuration: 4 legs total (2 ends + 2 middle at 940mm)  
Leg width: 20mm each  
Tolerance per gap: 5mm each side = 10mm per gap

**Formula:** (1900 - (20×3) - (10×4)) / 2  
- 1900mm total width
- Minus 60mm (3 leg widths in the middle - 2 middle legs + 1 divider concept)
- Minus 40mm (4 tolerance gaps)
= **910mm width per drawer**

#### Each Drawer Specifications

## CONSTRUCTION SEQUENCE

### Phase 1: Floor Preparation
1. Mark out bed footprint on floor (2246mm × 1222mm)
2. Install wooden plank base (173mm high, 1900mm × 900mm)
3. Ensure level and secure to floor
4. Install middle support legs at 940mm positions

### Phase 2: Left Wall Extension
1. Mark cutting line on existing wooden stud wall (100-200mm in)
2. Cut and remove plasterboard facing
3. Extend frame out 237mm with metal stud or matching timber
4. Install new plasterboard to create flush finish

### Phase 3: Metal Stud Frame Installation
1. **Floor tracks:**
   - Install 70mm floor track around perimeter
   - Leave gap for drawer access areas
   
2. **Vertical studs (400mm centers):**
   - Rear wall: full width (2246mm)
   - Head wall: 346mm depth
   - Front wall: full width with framing around access opening (1300mm × 580mm)
   - All studs cut to 1187.5mm (accounting for 12.5mm plasterboard top)

3. **Horizontal noggins:**
   - At 1150mm: all walls (shelf support)
   - At 975mm: rear wall only (tablet mount)
   - Around access opening: 530mm and 1110mm heights

4. **Head track:**
   - Install at 1187.5mm height (top of studs)

### Phase 4: Services
1. Route tablet power cable through rear wall cavity
2. Install any other electrical if required
3. Consider lighting (LED strips under shelf?)

### Phase 5: Plasterboard Installation
1. Fix 12.5mm plasterboard to metal frame
2. Leave bottom edge exposed below 173mm
3. Cut opening for access (1300mm × 580mm)
4. Install corner beads
5. Tape and joint all seams
6. Sand smooth
7. Prime and paint

### Phase 6: Bed Frame Construction
1. Build 357mm high frame around platform edge
2. Material: 18mm plywood or timber frame
3. Ensure mattress fits snugly (1900mm × 900mm)

### Phase 7: Shelving Installation
1. Cut rear shelf (2246mm × 210mm × 18mm)
2. Cut head shelf (346mm × 900/1110mm × 18mm)
3. Apply edge treatment
4. Place on top of stud walls
5. Secure from below or use brackets
6. Finish/seal as required

### Phase 8: Drawer Construction
1. Cut all drawer components
2. Assemble drawers (glue + pins/screws)
3. Apply finish to drawer fronts
4. Install floor-mounted runners
5. Fit drawers and adjust for smooth operation
6. Add handles/pulls

### Phase 9: Tablet Mount
1. Install mounting bracket at marked position (center, 975mm height)
2. Mount tablet
3. Connect power
4. Cable management

### Phase 10: Finishing Touches
1. Install curtain rail above access opening
2. Hang curtains
3. Add mattress
4. Final decoration/soft furnishings
5. Safety check all edges and corners

## SAFETY CONSIDERATIONS

1. **Edge Protection:** All sharp corners and edges should be rounded or protected
2. **Access Opening:** Ensure no sharp edges on opening perimeter
3. **Drawer Safety:** Ensure runners have stops to prevent complete removal
4. **Tablet Security:** Secure mounting to prevent falls
5. **Structural:** Ensure all frame connections are secure
6. **Weight Loading:** Shelves designed for typical book/toy loading (check with load calculations)
7. **Fire Safety:** Maintain access to electrical outlets and ensure proper cable management
8. **Ventilation:** Consider air circulation within enclosed space

---

## NOTES & RECOMMENDATIONS

1. **Metal Stud Selection:** 70mm C-studs recommended for strength and shelf support capability
2. **Shelf Finishing:** Flush-mount design allows comfortable leaning with pillows
3. **Drawer Access:** Floor-mounted runners allow easy operation from below bed level
4. **Left Wall Integration:** Carefully plan cut-in to existing wall to ensure structural integrity
5. **Plasterboard Quality:** Consider moisture-resistant board if room has humidity concerns
6. **Electrical:** Future-proof by running conduit for potential lighting additions
7. **Mattress:** Ensure good quality mattress with appropriate thickness (220mm specified)
8. **Ventilation:** Consider small ventilation gaps to prevent moisture buildup in enclosed space
